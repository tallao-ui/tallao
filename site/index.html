              F.01
              
      Readable by default
      
              
      Filled controls are derived from your accent and darkened until their text reaches 4.5:1, so a new colour doesn't cost you contrast.
      
            
      
            
      
              F.02
              
      Tested like an app
      
              
      240 tests in a real DOM and on the server, with automated accessibility checks, plus a SvelteKit app that checks hydration.
      
            
      
            
      
              F.03
              
      English and Spanish built in
      
              
      Every label the kit shows comes from one table you can replace or extend for a subtree with setLabels().
      
            
      
            
      
              F.04
              
      44px on touch screens
      
              
      Every control the kit draws has a 44px touch target under @media (pointer: coarse), and a test fails a component that lacks the rule.
      
            
      
            
      
              F.05
              
      Renders on the server
      
              
      Ids come from $props.id(), nothing touches window on import, and controls with a name submit in a plain form, also without JavaScript.

      Add tallao to this Svelte 5 project and use it for the UI.

1. Run: pnpm add github:tallao-ui/tallao
2. Import "tallao/tokens.css" and "tallao/base.css" once, in the root layout.
3. Read the component table in node_modules/tallao/README.md before
   writing markup, and use the kit's components instead of hand-made
   buttons, inputs, dialogs and tables. Never invent a prop.
4. To match my brand, set --ta-accent (and the other --ta-* tokens) in my
   own CSS. Do not edit the kit's files.
