              F.01
              
      Readable by default
      
              
      Filled controls are derived from your accent and darkened until their text reaches 4.5:1, so a new colour doesn't cost you contrast.
      
            
      
            
      
              F.02
              
      Tested like an app
      
              
      381 tests in a real DOM and on the server, with automated accessibility checks, plus a SvelteKit app that checks hydration.
      
            
      
            
      
              F.03
              
      English and Spanish built in
      
              
      Every label the kit shows comes from one table you can replace or extend for a subtree with setLabels().
      
            
      
            
      
              F.04
              
      44px on touch screens
      
              
      Every control the kit draws has a 44px touch target under @media (pointer: coarse), and a test fails a component that lacks the rule.
      
            
      
            
      
              F.05
              
      Renders on the server
      
              
      Ids come from $props.id(), nothing touches window on import, and controls with a name submit in a plain form, also without JavaScript.
      
            
      
            
      
              F.06
              
      One motion system
      
              
      Transitions come from tallao/motion on three durations and three easings, 120–240 ms, on opacity and transform. Reduced motion is one switch that the library and the tokens honour.
      
            
      
            
      
              F.07
              
      Written for coding agents too
      
              
      llms.txt lists every component with its props, generated from the sources and checked by the test suite, and a build-with-tallao skill tells an agent how to compose an agent run screen, an admin page or a dashboard.

      Add tallao to this Svelte 5 project and use it for the UI.

1. Run: pnpm add github:tallao-ui/tallao
2. Import "tallao/tokens.css" and "tallao/base.css" once, in the root layout.
3. Before writing markup, read llms.txt in the kit's repository: every
   component, its props and an example.
   https://raw.githubusercontent.com/tallao-ui/tallao/main/llms.txt
   Use the kit's components instead of hand-made buttons, inputs,
   dialogs and tables. Never invent a prop.
4. For an agent run screen, an admin page or a dashboard, copy the
   composition of src/AgentDemo.svelte, src/AdminDemo.svelte or the
   #dashboard section of src/App.svelte in that repository.
5. To match my brand, set --ta-accent (and the other --ta-* tokens) in my
   own CSS. Do not edit the kit's files.
